# 색깔 전환 슈팅 — COLOR SHIFT SHOOTER

빨강과 파랑을 번갈아 쓰며 싸우는 종스크롤 슈팅.
**공격은 반대 색으로, 방어는 같은 색으로** — 쏘는 순간과 맞는 순간 내 색이 무엇인지가 전부를 결정합니다.

캔버스로 그린 브라우저 게임이고, 설치 없이 링크만 있으면 바로 플레이할 수 있습니다.

## ▶ 플레이

**https://kimbo03.github.io/color-shift/**

## 규칙

| | |
|---|---|
| **공격은 반대 색** | 내 총알과 적의 색이 **다를 때만** 적이 파괴된다. 같은 색이면 총알이 흡수된다 |
| **방어는 같은 색** | 나와 **같은 색 적탄은 몸을 통과**하고 에너지가 찬다. 다른 색이면 체력이 깎인다 |
| **전환의 시차** | 색은 언제든 바꿀 수 있지만, **이미 발사된 총알은 쏜 순간의 색**을 유지한다 |
| **필살기** | 에너지 20칸을 채우면 적탄을 전부 점수로 바꾸고 모든 적에게 3 데미지 |

체력은 5칸, 피격 후 약 1.1초간 무적입니다.

## 조작법

| 입력 | 동작 |
|---|---|
| `←` `→` `↑` `↓` / `WASD` | 이동 |
| `Space` | 발사 (0.2초 쿨타임) |
| `Shift` / 마우스 우클릭 | 색 전환 |
| `F` / `Enter` | 필살기 (에너지가 가득 찼을 때) |
| `R` | 재시작 |
| 터치 | 하단 게임패드 — 스틱으로 이동, 발사 · 색 전환 · 필살기 버튼 |

키보드가 안 먹으면 게임 화면을 한 번 클릭해 주세요.

## 웨이브

총 8개입니다. 넘어갈 때마다 규칙이 하나씩 더해집니다.

| | |
|---|---|
| WAVE 1 | 같은 색 적은 총알이 튕긴다 |
| WAVE 2 | 두 색이 섞여 나온다 |
| WAVE 3 | 같은 색 총알은 통과 · 에너지 충전 |
| WAVE 4 | 스스로 색을 바꾸는 적 |
| **BOSS** | 1~3회 공격마다 색을 바꾼다 |
| WAVE 6 | 강화 편대 — 체력 · 속도 · 탄속 상승 |
| WAVE 7 | 강화 변색기 편대 — 3방향 사격 |
| **FINAL BOSS** | 무적 방벽 · 호위기 · 양색 탄막 |

웨이브 6과 최종 보스 시작 시 체력이 완전히 회복됩니다.

## 순위표

게임이 끝나면 **최종 점수와 도달 스테이지**가 자동으로 기록됩니다.
여러 번 플레이해도 가장 좋은 기록 하나만 남습니다 — 점수가 높은 판이 우선이고, 점수가 같으면 더 멀리 간 판이 남습니다.

- **개인 순위** 상위 30명, **반별 순위** 상위 10개 반(학년+반 단위). 그 아래면 내 줄이 따로 붙습니다
- 정보를 입력하지 않고 **게스트로 진행**할 수도 있습니다. 이때는 점수가 순위표에 남지 않습니다
- 순위표에는 **닉네임만** 공개됩니다. 학번과 이름은 공개되지 않으며 상품 지급 시 본인 확인용으로만 쓰입니다

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 소개 사이트 + 순위표. 게임을 iframe으로 불러옵니다 |
| `color-shift-shooter.html` | 게임 본체. 외부 참조 없는 단일 HTML |
| `ranking.js` | 정보 입력 · 기록 저장 · 순위 집계 |
| `firebase-config.js` | Firebase 설정값 |

네 파일이 같은 폴더에 있어야 합니다. 게임 파일만 따로 열어도 그대로 동작합니다.
